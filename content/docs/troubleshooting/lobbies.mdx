---
title: Lobby problems
description: Cannot create or join, lobby gone, lobby full.
---

## Unable to create lobby

**Why:** Missing auth, insufficient USDCx for paid entry, validation errors (player count, settings), or vault join failure.

**Fix:**

1. Confirm you are signed in.
2. Check Wallet balance ≥ entry (+ fees if shown).
3. Retry create after a failed vault tx only once the previous tx confirms or clearly fails.
4. Soft-refresh and try again with simpler settings.

**Retry:** After balance updates or the previous Stacks tx settles.

**Support:** Create still fails with a confirmed vault join tx id attached.

## Unable to join lobby

**Why:** Lobby full, private pending approval, insufficient balance, invalid/expired vault tx, or lobby already started/closed.

**Fix:**

1. Confirm status is still waiting.
2. For private rooms, wait for host approval.
3. Complete vault join with a fresh flow if the UI asks again.
4. Ask the host to re-invite if the room was recreated.

**Retry:** After approval or funding; do not spam joins with the same failed tx.

## Lobby no longer exists

**Why:** Host closed the room, it expired while idle, or the match already finished.

**Fix:** Return to **Lobbies** / game page and open a new room. Pending claims (if any) remain under **Wallet**.

**Retry:** N/A — create or join another lobby.

**Support:** You had a confirmed stake and no leave/claim path after expiry (include tx ids).
