---

## Connection lost

**Why:** Network change, sleeping tab, VPN, or a brief server blip.

**Fix:**

1. Check the connection indicator in the app.
2. Wait for automatic reconnect.
3. Refresh once if the room looks stuck.
4. Re-open the lobby link if you still cannot rejoin.

**Retry:** As soon as your network is stable.

**Support:** Disconnects that keep happening on a healthy network for more than ~10 minutes — note browser and connection type.

## Frequent reconnects

**Why:** Unstable mobile data or a flaky VPN.

**Fix:** Prefer a stable connection; try without VPN for the session; keep the room tab focused during important turns.

**Retry:** After switching networks. If the match continued, reopen the same room URL.
