## Workspace layout

| Path | Role |
|------|------|
| `backend/` | Cargo workspace: `sw-domain`, `sw-plugin`, `sw-server` |
| `frontend/` | Bun + Next.js arena UI |
| `checkers/`, `lexi-wars/`, `ludo/`, `ludo-rush/` | Game crates |
| `docs/` | This documentation site |
| `backend/sw-vault/` | Clarity + Solana vaults |

## Clone

```bash
git clone https://github.com/Stacks-Wars/backend.git
git clone https://github.com/Stacks-Wars/frontend.git
git clone https://github.com/Stacks-Wars/checkers.git
# …other games / docs as needed
```

## Run locally

Local/dev is the default. No `.env` required.

```bash
cd backend && docker compose up -d postgres redis
cargo run -p sw-server
cd frontend && bun install && bun run dev
```

New wallets get $50 test tokens on Stacks testnet and the local Solana mint.

Production is `sw-server --main` or `NETWORK=main`. Wars keys stay on Railway / Vercel.

Optional: `HIRO_API_KEY`, `HELIUS_API_KEY`, Google OAuth, Resend. See [Environment variables](/develop/environment).
