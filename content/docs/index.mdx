## How the platform works

1. **Sign in** with email + password / google OAuth.
2. A **custodial Stacks wallet** is created for you. You deposit **USDCx** to play.
3. Create or join a **lobby** for a registered game (free or paid).
4. When everyone is ready, the match runs live in the room.
5. After the match, winners **claim** payouts on-chain.

## For game developers

Build a Rust game with [`sw-plugin`](https://crates.io/crates/sw-plugin), add a frontend module, and set your **developer ID** from profile (**Get ID**) as `dev_id`.

Start at [Getting Started](/develop/getting-started).
