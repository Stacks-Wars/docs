## Create a lobby

1. Pick a game → **Create lobby** (or use Lobbies → create).
2. Choose entry amount (or free), privacy, and player settings.
3. For **paid** lobbies you need enough USDCx. The app stakes your entry on-chain, then opens the room.
4. You land in the waiting room as host.

If create fails, see [Troubleshooting](/troubleshooting/lobbies).

## Join a lobby

1. Open a lobby from Games or Lobbies.
2. **Paid:** confirm the stake, then join.
3. **Private:** wait for host **approval** if requested.
4. Ready up; the host starts when everyone is set.

## Free vs paid

| | Free | Paid |
|--|------|------|
| Entry | None | USDCx entry fee |
| Pot | None | Escrowed entry fees |
| After the match | Stats / points | Winners claim payouts |

**Sponsored** lobbies can waive entry for players — the room UI shows when that applies.

## Lobby lifecycle

1. **Waiting** — players join and ready up.
2. **In progress** — the match is live.
3. **Finished** — results shown; claim winnings if paid.
4. **Closed** — room is gone; open a new lobby from the list.
