---
title: Navigating the app
description: Main areas of the Stacks Wars web app.
---

| Area | What it is |
|------|------------|
| **Games** | Catalog of registered games; open a game to see lobbies and activity |
| **Lobbies** | Browse open rooms across games; create or join |
| **Room** | Waiting room + live match for one lobby |
| **Wallet** | Balance, deposit address, withdraw, pending claims, activity |
| **Leaderboard** | Season rankings and points |
| **Profile** | Public stats, match history, achievements (`/profile/[username]`) |
| **Settings** | Account, profile fields, preferences |

Use the shell navigation and user menu for wallet balance and account links. Deep links into a room use the lobby path allocated when the room was created.
