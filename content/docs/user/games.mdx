## Catalog

Each game lists:

- Name and description
- Min / max players
- Categories
- Developer fee (share of the pot, up to 5%)

## Playable games

A game is ready to play when both the server and the website support it. Available today: Checkers, Lexi Wars, Ludo, Ludo Rush.

## Game pages

Open a game to see open lobbies, recent activity, and how it works. From there you create a lobby or join one.
