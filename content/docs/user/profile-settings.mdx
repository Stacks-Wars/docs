## Profile

Public profiles live at `/profile/[username]` and show:

- Season rank / points / win rate
- Match history
- Achievements
- Favourite games
- Season history

### Your developer ID

On **your own** profile only, use **Get ID** to copy your platform user UUID for game registration (`dev_id`). Other visitors never see this control.

## Settings

Under **Settings** you can update:

- Username / display name / avatar
- Account overview (email, account id, deposit address)

Keep username unique and appropriate — it is part of your public URL.
